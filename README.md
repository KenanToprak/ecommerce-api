# FastAPI E-Commerce API 🚀

A modern, fast, and robust E-Commerce API built with Python, FastAPI, and PostgreSQL. This project demonstrates best practices in backend development, including layered architecture, JWT authentication, data validation, and database modeling.

## Features ✨

*   **FastAPI:** High performance, easy to learn, fast to code, ready for production.
*   **PostgreSQL & SQLAlchemy:** Relational database management with an ORM for complex data modeling.
*   **Authentication:** Secure JWT (JSON Web Token) based authentication with Bcrypt password hashing.
*   **Pydantic:** Strict data validation and settings management using python type annotations.
*   **Layered Architecture:** Clean code organization separating routes, business logic (CRUD), models, and schemas.
*   **Automatic Documentation:** Interactive API documentation provided by Swagger UI (automatically generated by FastAPI).

## Tech Stack 🛠️

*   **Language:** Python 3.9+
*   **Framework:** FastAPI
*   **Database:** PostgreSQL
*   **ORM:** SQLAlchemy
*   **Data Validation:** Pydantic
*   **Authentication:** Passlib (Bcrypt), Python-Jose (JWT)
*   **Server:** Uvicorn

## Project Structure 📁

```text
ecommerce_api/
│
├── api/                 # API Routers and Dependencies
│   ├── endpoints/       # Specific route definitions (auth, products, orders)
│   └── deps.py          # Dependencies (e.g., get_current_user)
├── core/                # Core configurations
│   ├── config.py        # Environment variables and app settings
│   ├── database.py      # Database connection setup
│   └── security.py      # Hashing and JWT token generation
├── crud/                # Create, Read, Update, Delete database operations
├── models/              # SQLAlchemy Database Models (Tables)
├── schemas/             # Pydantic Schemas (Data Validation)
├── main.py              # Application Entry Point
└── requirements.txt     # Python Dependencies
```

## How to Run Locally 💻

1. **Clone the repository**
   ```bash
   git clone <your-repository-url>
   cd ecommerce_api
   ```

2. **Create a Virtual Environment**
   ```bash
   python -m venv venv
   # On Windows:
   .\venv\Scripts\activate
   # On Linux/Mac:
   source venv/bin/activate
   ```

3. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Set up PostgreSQL Database**
   * Create a PostgreSQL database named `ecommerce_db`.
   * Update the `DATABASE_URL` in `core/config.py` with your credentials if necessary.

5. **Run the Application**
   ```bash
   uvicorn main:app --reload
   ```

6. **Explore the API**
   * Open your browser and go to: `http://127.0.0.1:8000/docs` to interact with the API via Swagger UI.
